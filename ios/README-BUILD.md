# Building the iOS app

This `ios/` folder is a real, self-contained Xcode project generated by
Capacitor (`npx cap add ios`) — it wraps the same `dist/` web build used by
the Android, Electron, and PWA builds in a native WKWebView shell. It uses
Swift Package Manager (not CocoaPods) to resolve Capacitor's dependencies,
so there's no separate `pod install` step — Xcode resolves those
automatically the first time you open the project.

**This part requires an actual Mac.** Xcode only runs on macOS, and Apple
doesn't offer any way around that — there's no cross-compiling an iOS build
from Windows/Linux the way Android's Gradle build works anywhere. Everything
up to this point (running `npx cap add ios`, editing the app itself) doesn't
need a Mac; building and installing it onto a device does.

## Building and installing on your own device (free, no paid Apple account)

1. Copy this whole repo to a Mac (or clone it there / pull the branch).
2. On the Mac: `npm install`, then `npm run ios:sync` — this builds the web
   app and copies it into `ios/App/App/public`.
3. Open `ios/App/App.xcodeproj` in Xcode (or run `npx cap open ios`, which
   does the same thing).
4. Select the `App` target → **Signing & Capabilities** tab → check
   **Automatically manage signing** → sign in with your own Apple ID under
   **Team** (Xcode → Settings → Accounts, if it's not listed yet). A free
   Apple ID works for this — you don't need the $99/year Developer Program
   to run your own build on your own device, only to distribute it to
   others or keep it installed indefinitely without reconnecting.
5. Plug your iPhone into the Mac via USB (or pair it wirelessly in Xcode →
   Window → Devices and Simulators), select it as the run destination in
   Xcode's toolbar, and hit **Run** (▶).
6. First launch: on the iPhone, go to **Settings → General → VPN & Device
   Management** and trust the developer certificate Xcode just installed —
   iOS blocks apps from an unrecognized developer profile until you do this
   once.

**The free-account caveat**: an app signed this way stops launching after
**7 days** and needs re-installing from Xcode (same USB connection, hit Run
again) to keep working. A paid Apple Developer Program membership removes
that limit (signs for a full year instead) — worth it only if you want to
keep testing past a week without reconnecting to the Mac each time.

Whenever the web app itself changes (any edit under `src/`), re-sync before
building again:

```sh
npm run ios:sync
```

then Run again from Xcode — it picks up the refreshed `public/` contents
automatically.
