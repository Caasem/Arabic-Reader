## Always bundled

| Data | Used for | Source and licence |
| --- | --- | --- |
| `public/dictionary-data/` | The built-in Arabic → English dictionary (AraMorph) | Derived from Tim Buckwalter's AraMorph analyzer via the Linguistic Data Consortium, GPLv2. The licence text is in `GPL.redistributable.txt`, with attribution in `SOURCE-README.md`, in that folder. The data reached the app by way of the arabic-dict-chrome project. |
| `public/vocab-list-data/the-list.tsv` | Vocabulary Levels (word frequency) | Built from the Annotated King Saud University Corpus of Classical Arabic (KSUCCA), annotated by Yonatan Belinkov. How the list was built is in `SOURCE-README.md`. The corpus's own licence has not been checked here: **licence unverified**. |
| `public/fonts/NotoNaskhArabic-*.woff2` | Arabic text | Noto Naskh Arabic, Google Fonts. No licence file in the repo: **licence unverified** (Noto fonts are normally published under the SIL Open Font License). |
| `public/fonts/Lala.ttf` | Arabic reading font | **Licence unverified.** Confirm that this font may be redistributed before publishing more widely. |

## Optional dictionaries (off by default, loaded on demand)

| Dictionary | Data | Source and licence |
| --- | --- | --- |
| Al-Muʿjam al-Wasīṭ | `public/alwasit-data/` | Extracted from the [arabic_lexicons](https://github.com/wizsk/arabic_lexicons) project (GPL-3.0). The dictionary is a 20th-century work (Arabic Language Academy, Cairo, first published 1960) whose copyright status is **not clean-cut**. Included in good faith; verify before redistributing beyond personal use. |
| Al-Ṣiḥāḥ | `public/alsihah-data/` | al-Jawharī's work (d. c. 1002), public domain. Digital text from arabic_lexicons v3.5.0 (GPL-3.0), which compiled it from a modern critical edition. |
| Maqāyīs al-Lugha | `public/almaqayis-data/` | Aḥmad ibn Fāris (d. 1004), public domain. Digital text from arabic_lexicons v3.5.0 (GPL-3.0). |
| Baranov (Arabic–Russian) | repo-root `russian.txt` | Resembles Kh. K. Baranov's *Arabic–Russian Dictionary* and matches a file in ApayRus/meteor-arabic-dictionary. **Provenance and licence unverified**: Baranov's dictionary is a copyrighted work, and no licence text backs up the claim that this data is open. Do not redistribute the built app beyond personal use until this is settled. Users can also load their own copy in Settings. |

Regenerate the lexicon data with `python scripts/extract-lexicon-data.py path/to/db.sqlite`.

## Code loaded on demand

Loaded only when a TXT, Markdown, MOBI or AZW3 file is added (`src/importFormats`) or an Anki package is exported (`src/anki`).

| Library | Used for | Licence |
| --- | --- | --- |
| [marked](https://github.com/markedjs/marked) | Markdown to HTML | MIT |
| [foliate-js](https://github.com/johnfactotum/foliate-js) (`mobi.js`) | Reading MOBI and AZW3 (KF8) files | MIT |
| [fflate](https://github.com/101arrowz/fflate) | Decompressing fonts inside Kindle files | MIT |
| [sql.js](https://github.com/sql-js/sql.js) | Writing Anki packages (.apkg), loaded only on export | MIT |
